01 / EL PROYECTO

Una idea que pone
la tecnología al servicio
de las personas.

Este proyecto desarrolla un sistema capaz de identificar señas dinámicas de la Lengua de Señas Mexicana a partir del análisis del movimiento.

Mediante una cámara y técnicas de visión computacional, el sistema obtiene información de puntos clave del cuerpo, las manos y el rostro. Después analiza una secuencia de fotogramas para generar una predicción.
